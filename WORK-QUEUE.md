## Standing rules for this project

- Source of truth is `src/`; `site/` and `dist/` are generated by
  `npm run build`. Never hand-edit `site/`.
- Screenshot / measure every change before reporting it done.
- Push to GitHub before any Vercel deploy (`npm run deploy`).
- Taste: tight spacing, slim chrome, no fat boxes, no wasted vertical space.
